# VidSnap Pro — Free Video Downloader

A modern, professional video downloader website built for Blogger and GitHub Pages.

## Features
- 🎨 Dark Glassmorphism UI
- 📥 Video download via Cobalt API (1000+ sites — YouTube, TikTok, Instagram, Twitter, Facebook)
- 📱 Android APK download button
- 💰 Google AdSense ad slots (4 pre-placed)
- 📱 Fully mobile responsive
- ⚡ Auto clipboard paste, Enter key shortcut, toast notifications

## Setup
1. Replace `ca-pub-XXXXXXXXXXXXXXXX` with your AdSense Publisher ID in `blogger-template.xml`
2. Replace `YOUR_APK_LINK_HERE` with your APK direct download URL
3. Upload `blogger-template.xml` to Blogger → Theme → Edit HTML

## Files
- `preview.html` — Standalone preview (GitHub Pages live site)
- `blogger-template.xml` — Full Blogger XML template
- `index.html` — Redirect to preview

## Tech Stack
- Pure HTML/CSS/JavaScript
- Cobalt API (free, no API key)
- Google AdSense
- Font Awesome 6.5
- Google Fonts (Inter)
